# itskamol/homebrew-tern

Homebrew tap for [tern](https://github.com/itskamol/tern), a fast, low-memory SSH terminal for macOS.

```sh
brew install --cask itskamol/tern/tern
```

tern updates itself once installed (Settings → About). Builds are signed with a local
certificate, not notarised; the cask clears the quarantine flag so macOS opens them.
